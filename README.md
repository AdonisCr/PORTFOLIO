# Portfolio — Adonis OUSSOU

Portfolio personnel en React 18, TypeScript et Vite. Il présente les projets, compétences, expériences et coordonnées de l'auteur.

## Commandes utiles

```bash
npm run dev     # lancer le site en local
npm run lint    # vérifier le code
npm run build   # compiler la version de production
```

Les projets affichés sont décrits dans `src/lib/projectsData.ts` et les captures réelles sont dans `public/projects/`.
