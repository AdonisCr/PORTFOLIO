---
name: baseline-ui
description: Remove generic AI patterns from UI output. Enforce distinctive design choices.
---

NEVER use:
- Inter, Roboto, Arial, system-ui as primary fonts
- Purple gradients on dark backgrounds (already used — find a different accent)
- Generic card grids with equal padding
- Placeholder shimmer as the only loading state
- Cookie-cutter hero sections with centered h1 + subtitle + CTA button

ALWAYS:
- Pick ONE strong typographic personality per project and commit to it
- Use asymmetry intentionally
- Animate with purpose (not just because motion.div exists)
- Vary card sizes, weights, and hierarchy within the same list
- Make hover states surprising, not just opacity changes
